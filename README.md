# Optimizing KNN Performance with Dimensionality Reduction

## Project Overview
This project studies how dimensionality reduction techniques improve the performance of the K-Nearest Neighbors (KNN) algorithm.

## Dataset
- Breast Cancer Dataset from kaggle
- 4024 samples
- 30 numerical features
- Binary classification (malignant / benign)

## Objective
- Build a baseline KNN model
- Apply PCA and LDA
- Compare performance before and after dimensionality reduction
